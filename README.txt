NoteMap V1.12

Mới trong bản này:
- Thêm nút Edit trên từng ảnh trong phần Thuộc tính của note.
- Click ảnh để hiện Edit + nút thùng rác; bấm Edit để mở popup chỉnh sửa ảnh.
- Image editor có các công cụ: Select, Rectangle, Ellipse, Free draw, Arrow, Text và Eraser.
- Có chọn màu nét, độ dày, opacity và fill opacity cho vùng Rectangle/Ellipse.
- Select cho phép chọn, kéo di chuyển đối tượng; Rectangle/Ellipse có 4 điểm góc để resize.
- Có Undo/Redo riêng ngay trong popup ảnh, Clear toàn bộ annotation và Delete vùng đang chọn.
- Có zoom +/-, Fit và 100%.
- Annotation được lưu dạng vector riêng trong file .notemap, không ghi đè ảnh gốc; lần sau mở lại vẫn có thể Edit tiếp.
- Ctrl+Z / Ctrl+Y khi popup ảnh đang mở chỉ Undo/Redo thao tác trên ảnh; khi đóng popup sẽ Undo/Redo toàn dự án như V1.11.

Cách dùng nhanh:
1. Chọn một note và chèn ảnh bằng nút Ảnh.
2. Click trực tiếp vào ảnh để hiện nút Edit ở góc trên trái.
3. Bấm Edit.
4. Chọn Rectangle / Free draw / Arrow / Text... rồi đánh dấu trên ảnh.
5. Bấm "Lưu thay đổi" để lưu annotation vào note.
6. Ctrl+S để lưu toàn bộ dự án thành file .notemap.

Phím tắt chính:
- Ctrl + S: lưu dự án .notemap
- Ctrl + Z: Undo
- Ctrl + Y: Redo
- Ctrl + Shift + Z: Redo
- Ctrl + K: tìm note
- N: tạo note mới
- Delete: xóa đối tượng đang chọn trong popup ảnh hoặc xóa note/dây ở workspace
