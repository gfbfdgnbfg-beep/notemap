Thuộc tính

Chọn một note để chỉnh sửa hoặc bấm vào dây nối để chọn dây.

N tạo note • kéo phần tiêu đề để di chuyển • kéo từ bất kỳ chấm tròn nào sang đúng chấm tròn bạn muốn nối.
Có thể định dạng như Word, chèn ảnh hoặc tải file trực tiếp vào note. Ảnh và file đính kèm được lưu bên trong file .notemap.
Dây nối đang chọn
Hai điểm đầu dây sẽ chuyển sang màu vàng. Giữ chuột trái vào một điểm vàng rồi kéo:
• Thả vào điểm tròn khác → đổi đầu nối sang đúng điểm đó.
• Thả ra vùng trống → gỡ dây nối.
• Nháy đúp chuột trái trực tiếp lên dây → xóa nhanh.
